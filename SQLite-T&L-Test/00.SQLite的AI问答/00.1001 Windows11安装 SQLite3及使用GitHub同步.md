### 第一部分：Windows 11 安装 SQLite3

在 Windows 上安装 SQLite3 非常简单，无需复杂的安装程序，核心就是**下载、解压、配置环境变量**三步。

**1. 下载 SQLite3 工具包**
*   访问 SQLite 官方下载页面：【`https://www.sqlite.org/download.html`】(https://www.sqlite.org/download.html)。
*   在 "Precompiled Binaries for Windows" 区域，下载 **`sqlite-tools-win-x64-*.zip`**。这个压缩包包含了我们需要的 `sqlite3.exe` 命令行工具。

**2. 解压并放置文件**
*   将下载的 `.zip` 文件解压到一个你容易找到的文件夹，例如 `C:\sqlite`。解压后，你应该能在该文件夹内看到 `sqlite3.exe` 文件。

**3. 配置环境变量（关键步骤）**
配置环境变量的目的是让你在电脑的任何位置，都能通过命令行直接运行 `sqlite3`。
*   在Windows搜索栏输入“**环境变量**”，并打开“**编辑系统环境变量**”。
*   在打开的“系统属性”窗口中，点击“**环境变量**”按钮。
*   在“**系统变量**”列表中，找到并双击 **`Path`** 变量。
*   点击“**新建**”，然后输入你刚才解压SQLite的文件夹路径，例如 `C:\sqlite`。
*   依次点击“确定”，保存所有设置。

**4. 验证安装**
*   按下 `Win + R`，输入 `cmd` 并回车，打开命令提示符。
*   输入 `sqlite3` 并回车。
*   如果看到类似 `SQLite version 3.xx.x ...` 的信息，并出现 `sqlite>` 提示符，就说明安装成功了。

### 第二部分：为 GitHub 项目设置 `.gitignore`

`.gitignore` 文件用来告诉 Git 哪些文件不需要纳入版本控制。

**1. 创建 `.gitignore` 文件**
在你的 Git 仓库**根目录**下创建名为 `.gitignore` 的文件。
*   **方法一（图形界面）**：在文件夹中右键 -> 新建 -> 文本文档，然后重命名为 `.gitignore`（包括点）。
*   **方法二（命令行）**：在项目目录下打开终端，执行 `touch .gitignore`。

**2. 编写忽略规则**
用文本编辑器打开 `.gitignore` 文件，将你想忽略的文件或文件夹按规则写入，每行一个。

**基础规则示例：**
```gitignore
# 忽略所有 .log 结尾的文件
*.log

# 忽略根目录下的 temp 文件夹
/temp/

# 忽略 build 文件夹下的所有内容
build/

# 忽略特定文件
config.local.json
```

**3. 为 SQLite 项目配置忽略规则**
数据库文件是二进制文件，不应提交到 Git 仓库。将以下规则添加到你的 `.gitignore` 文件中：
```gitignore
# 忽略所有 SQLite 数据库文件
*.db
*.sqlite
*.sqlite3

# 忽略 SQLite 日志和 WAL 文件
*.db-journal
*.db-wal
*.db-shm
```
如果之前已经提交过数据库文件，需要先让Git停止追踪：`git rm --cached db.sqlite3`。

**4. 其他实用建议**
*   **使用模板**：GitHub 提供了针对各种项目的官方 `.gitignore` 模板，访问 [`github/gitignore`](https://github.com/github/gitignore) 仓库可以找到。
*   **在线生成器**：访问 [`gitignore.io`](https://www.toptal.com/developers/gitignore) 网站，选择你的操作系统、IDE和编程语言，它会自动生成合适的 `.gitignore` 文件。
*   **全局忽略**：对于个人编辑器产生的临时文件，可以设置全局忽略，避免在每个项目里重复配置。
