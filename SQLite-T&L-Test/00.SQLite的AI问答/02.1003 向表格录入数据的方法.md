向 `users` 表输入数据，有 **4 种递进的方法**。你提到的“快速输入”通常指**批量运行脚本**或**导入文件**，我按从慢到快的顺序给你列全，重点放在你需要的“脚本化”操作上。

假设你的 `users` 表结构为：`id INTEGER PRIMARY KEY, name TEXT, age INTEGER`。

---

### 方法一：单条插入（基础）
适合测试时随手加一条。
```sql
INSERT INTO users (name, age) VALUES ('张三', 25);
```
**注意**：如果一次只插一条，多条数据需重复执行，比较慢。

---

### 方法二：单条语句插入多条（批量 SQL）
适合数据量中等（几十到几百条），写在一个命令里，比逐条快很多。
```sql
INSERT INTO users (name, age) VALUES 
    ('李四', 30),
    ('王五', 28),
    ('赵六', 35);
```

---

### 方法三：运行外部 SQL 脚本（你问的“运行脚本”）
这是最标准的“跑脚本”方式。把 SQL 语句写在 `.sql` 文件里，一次性全部执行。

**步骤 1**：新建一个文本文件，比如 `insert_data.sql`，写入内容：
```sql
-- 建议开启事务，速度极快（见下文“加速秘籍”）
BEGIN TRANSACTION;
INSERT INTO users (name, age) VALUES ('Alice', 22);
INSERT INTO users (name, age) VALUES ('Bob', 27);
INSERT INTO users (name, age) VALUES ('Cathy', 24);
-- 如果有上百条，就这样一直写下去
COMMIT;
```

**步骤 2**：在 `sqlite3` 命令行中执行该脚本：
```sql
.read insert_data.sql
```
或者，**不必进入交互界面**，直接在操作系统终端（CMD 或 Bash）执行：
```bash
sqlite3 test.db < insert_data.sql
```

---

### 方法四：导入外部数据文件（极速批量，适合大量数据）
如果你已有现成的 CSV（逗号分隔）或 TSV 数据，这是**最快**的方式，无需写 SQL 语句。

**步骤 1**：准备 CSV 文件 `data.csv`，内容如下（注意表头要与表字段对应）：
```csv
name,age
孙七,40
周八,32
吴九,29
```

**步骤 2**：在 `sqlite3` 命令行中执行导入（SQLite 3.32+ 版本）：
```sql
.mode csv
.import data.csv users
```
**如果版本较低**，则用以下传统方式：
```sql
.mode csv
.import data.csv temp_table
INSERT INTO users (name, age) SELECT name, age FROM temp_table;
DROP TABLE temp_table;
```

---

### 🚀 加速秘籍（针对方法二和三，极其重要）
如果你在脚本里有**几百上千条** `INSERT`，**一定要用事务包裹**，否则 SQLite 默认每条语句都自动提交（要写一次磁盘），速度会慢 100 倍以上。

**慢的写法（千万避坑）**：
```sql
INSERT INTO users VALUES (1,'a',10);  -- 自动提交一次
INSERT INTO users VALUES (2,'b',20);  -- 自动提交一次
```

**快的写法（开启显式事务）**：
```sql
BEGIN;
INSERT INTO users VALUES (1,'a',10);
INSERT INTO users VALUES (2,'b',20);
-- ... 中间一万条 ...
COMMIT;  -- 仅提交一次，瞬间完成
```

### 终极速查对比表

| 方法 | 适用场景 | 速度级别 | 命令/操作 |
| :--- | :--- | :--- | :--- |
| **单条插入** | 随手加 1-2 条测试数据 | 慢 | `INSERT INTO ... VALUES (...);` |
| **多值插入** | 一次性加几十条已知数据 | 中等 | `INSERT INTO ... VALUES (..),(..);` |
| **运行 .sql 脚本** | 已有写好的 SQL 文件，或数据量中等（几百条） | **快（配合事务）** | `.read insert_data.sql` |
| **导入 CSV 文件** | 从 Excel 或系统导出的海量数据（上万条） | **极快（原生批量导入）** | `.mode csv` + `.import data.csv users` |

1. 用记事本新建 `test.sql`，复制上面的 `BEGIN...COMMIT` 示例。
2. 在 `sqlite3` 中输入 `.read test.sql`。
