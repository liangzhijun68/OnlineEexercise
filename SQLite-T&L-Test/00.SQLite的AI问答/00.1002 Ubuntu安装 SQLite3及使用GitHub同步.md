### 第一部分：Ubuntu 中安装 SQLite3

在 Ubuntu（以及大多数 Debian 系 Linux）下安装 SQLite3 极其简单，只需一条命令：

**1. 更新软件源并安装**
打开终端（Ctrl+Alt+T），执行：
```bash
sudo apt update
sudo apt install sqlite3 -y
```
如果你后续需要编译依赖 SQLite 的程序（如 Python 的 `sqlite3` 模块），建议顺便安装开发库：
```bash
sudo apt install libsqlite3-dev -y
```

**2. 验证安装**
```bash
sqlite3 --version
```
如果显示版本号（如 `3.37.2`），即表示安装成功。输入 `sqlite3` 回车即可进入交互式命令行，输入 `.exit` 退出。

### 第二部分：关于“项目不在根目录”如何设置 .gitignore

**首先要纠正一个关键概念**：Git 里的“根目录”**不是**指 Linux 的系统根目录 `/`，而是指**你的 Git 仓库根目录**（即包含 `.git` 隐藏文件夹的那个目录）。

无论你的项目物理路径是 `/home/用户名/Desktop/my_project` 还是 `/var/www/html/app`，**只要进入这个文件夹，它就是这个仓库的“根目录”**。`.gitignore` 必须放在这个目录下才生效。

针对你担心的“项目不在根目录”情况，有且仅有以下两种处理方式：

#### 情况 1：项目本身就是仓库（最常见）
你的项目文件夹（比如 `/home/用户名/code/myapp`）就是仓库根目录（里面有 `.git` 文件夹）。
👉 **操作方法**：直接将 `.gitignore` 文件创建在 `/home/用户名/code/myapp/` 下即可。

#### 情况 2：你的项目只是大仓库里的一个子文件夹
比如大仓库在 `/home/用户名/code/`，而你的项目在 `/home/用户名/code/sub_project/`。此时 `.git` 文件夹在 `code` 目录下。
👉 **操作方法**：你可以**在 `sub_project` 子文件夹里单独创建一个 `.gitignore` 文件**。Git 会智能合并，子文件夹里的 `.gitignore` 只负责忽略该子文件夹及其内部的内容（路径相对于子文件夹本身）。

### 第三部分：针对 SQLite 项目的 .gitignore 配置建议

无论你把 `.gitignore` 放在仓库根目录还是子文件夹，针对 SQLite 项目，**必须忽略数据库实体文件**，防止将几十 GB 的二进制数据提交到 GitHub。

在 `.gitignore` 中写入以下内容：

```gitignore
# 忽略所有 SQLite 数据库文件（不管放在哪个子目录）
*.db
*.sqlite
*.sqlite3

# 忽略运行时产生的临时日志与回滚文件
*.db-journal
*.db-wal
*.db-shm

# 如果你的项目有迁移文件或本地配置文件
migrations/
config.local.*
```

**特别提醒**：如果你以前不小心把 `*.db` 提交上去了，仅仅在 `.gitignore` 里添加是没用的（Git 已经追踪了）。你需要先执行以下命令清除 Git 缓存：
```bash
# 假设你误提交了 database.sqlite3
git rm --cached database.sqlite3
# 然后再把 .gitignore 提交生效
git add .gitignore
git commit -m "fix: 忽略数据库文件"
```

### 终极建议：不用手动造轮子
如果觉得写规则麻烦，直接在项目根目录（子文件夹也行）执行以下命令，利用 GitHub 官方模板生成通用规则：
```bash
# 如果你的项目是 Python 项目
curl -o .gitignore https://raw.githubusercontent.com/github/gitignore/main/Python.gitignore

# 如果是 Go 项目
curl -o .gitignore https://raw.githubusercontent.com/github/gitignore/main/Go.gitignore
```
这些官方模板已经包含了 SQLite 常见的忽略规则，你只需要在此基础上追加自己项目的特殊文件即可。

**总结一句话**：`.gitignore` 放在哪里，取决于 `.git` 文件夹在哪里；如果项目是大仓库的子目录，直接在子目录里新建一个 `.gitignore` 就行，路径写法完全一样。😊
