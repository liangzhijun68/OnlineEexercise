在SQLite命令行（`sqlite3`）中，这两个操作分别使用**点命令**和**SQL查询语句**来完成，我给你最直观的写法：

---

### 1. 查看当前数据库里的全部表

使用点命令 **`.tables`**

```sql
.tables
```
**执行效果**：会列出当前数据库连接中所有的表名，按字母顺序排列，例如：
```
users  orders  products  logs
```

**补充技巧**：
- 如果表太多，可以加通配符筛选，例如只看以 `u` 开头的表：
  ```sql
  .tables u%
  ```

- 如果想看表的**创建语句**（表结构），使用：
  ```sql
  .schema 表名          -- 查看指定表
  .schema               -- 查看所有表的创建语句
  ```

---

### 2. 查看一个表里的全部内容

使用 SQL 查询语句 **`SELECT * FROM 表名;`**

```sql
SELECT * FROM users;
```
**执行效果**：会显示 `users` 表中的所有行和所有列。

---

### 3. 进阶：让查看内容更"好看"（推荐）

如果表里的数据列很多，默认的显示会很乱。建议在执行查询前，先开启两个设置：

```sql
.headers ON        -- 显示列名（表头）
.mode column       -- 改为表格对齐模式（而不是默认的列表模式）
```

**设置后的效果对比**：

| 未设置（默认）    | 已设置（headers ON + mode column） |     |                                                             |
| :--------- | :---------------------------- | --- | ----------------------------------------------------------- |
| `张三        | 25                            | 北京` | `name  age  city` <br> `----  ---  ----` <br> `张三  25   北京` |
| 数据挤在一起，看不清 | 清晰对齐，一目了然                     |     |                                                             |

---

### 4. 查看部分数据（防止刷屏）

如果表里有成千上万条数据，直接 `SELECT *` 会把屏幕刷爆。建议加 **`LIMIT`** 限制行数：

```sql
-- 只看前 10 行
SELECT * FROM users LIMIT 10;

-- 查看第 11 到 第 20 行（分页查看）
SELECT * FROM users LIMIT 10 OFFSET 10;
```

---

### 5. 完整的操作流程演示

假设你刚刚进入 `sqlite3 test.db`，想快速了解这个数据库：

```sql
-- 1. 先看有哪些表
.tables

-- 2. 看看 users 表长什么样（结构）
.schema users

-- 3. 调整显示格式
.headers ON
.mode column

-- 4. 看前 20 条数据
SELECT * FROM users LIMIT 20;
```

---

### 快速命令速查卡

| 目的 | 命令 |
| :--- | :--- |
| 列出所有表 | `.tables` |
| 查看表结构（建表语句） | `.schema 表名` |
| 查看表全部数据 | `SELECT * FROM 表名;` |
| 查看表前N行 | `SELECT * FROM 表名 LIMIT N;` |
| 让数据显示更整齐 | 先执行 `.headers ON` 和 `.mode column` |
| 退出 `sqlite3` | `.quit` |
