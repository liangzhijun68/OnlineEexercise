在SQLite中，“查看一行”和“查看一列”的语法完全不同，我来给你最精准的写法，再附赠一个“查看一个格子”的技巧：

---

### 1. 查看指定的一列（所有行的该列数据）

使用 `SELECT 列名 FROM 表名;`

```sql
-- 查看 users 表中所有用户的 name 列
SELECT name FROM users;

-- 查看多个列（比如只看姓名和年龄）
SELECT name, age FROM users;
```

**注意**：如果表里有10万行，这会刷屏。建议加 `LIMIT` 限制条数：
```sql
SELECT name FROM users LIMIT 10;   -- 只看前10个名字
```

---

### 2. 查看指定的一行（该行的所有列数据）

使用 `SELECT * FROM 表名 WHERE 条件;` 或者用 `LIMIT 1`

```sql
-- 方式一：根据主键查（最精准）
SELECT * FROM users WHERE id = 3;

-- 方式二：根据姓名查（如果有重名会返回多条）
SELECT * FROM users WHERE name = '张三';

-- 方式三：随便看一条数据（不管哪条）
SELECT * FROM users LIMIT 1;
```

---

### 3. 延伸技巧：查看“一个格子”（指定行 + 指定列）

如果你想精确到某一行某一列，比如“查看 id=3 的用户的年龄”：

```sql
SELECT age FROM users WHERE id = 3;
```

---

### 4. 📌 让查看结果更清晰的“官方设置”

如果你只想看一行，但这一行有几十个字段，屏幕显示会挤成一团。这时推荐使用 **`.mode line`**（竖排显示），效果是**字段名和值分两列**，非常易读：

```sql
.mode line
SELECT * FROM users WHERE id = 3;
```
**执行效果**：
```
   id = 3
 name = 张三
  age = 25
city = 北京
```

---

### 命令速查卡（直接复制用）

| 你想看什么 | 命令（复制即用） |
| :--- | :--- |
| 只看 `name` 这一列 | `SELECT name FROM users;` |
| 只看 `age` 这一列的前20行 | `SELECT age FROM users LIMIT 20;` |
| 只看 `id=5` 的这一整行 | `SELECT * FROM users WHERE id = 5;` |
| 随便看一行数据（通常用于验表） | `SELECT * FROM users LIMIT 1;` |
| 查看某人的具体年龄（行列交叉） | `SELECT age FROM users WHERE name = '张三';` |

**注**：如果你的表名或列名包含特殊字符，记得用双引号包起来；普通英文和中文直接写即可。如果查出来是空的（0 rows），说明没有匹配的数据，检查一下条件是否正确。😊
